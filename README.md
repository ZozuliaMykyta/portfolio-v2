# 💼 Portfolio v2

**Portfolio v2** is a modern personal portfolio website built with **React**, **TypeScript**, and **Tailwind CSS**. It showcases projects, skills, and provides contact information in a clean, responsive interface.

---

## 🚀 Features

- ⚛️ React + TypeScript for a modern, type-safe frontend.
- 🎨 Styled with Tailwind CSS for rapid, utility-first UI development.
- 📱 Fully responsive design for a great experience on all devices.
- ⚡️ Built with Vite for a fast and efficient development workflow.
- 🧩 Utilizes React Icons for a wide range of vector icons.

---

## 🔧 Tech Stack

| Technology         | Purpose                        |
|--------------------|--------------------------------|
| React + TypeScript | Frontend UI & Logic            |
| Tailwind CSS       | Styling and responsive design  |
| Vite               | Build tool & development server|
| React Icons        | Icon library                   |

---

## 📥 How to Copy and Run This Project

### 1. Clone the repository
```bash
git clone https://github.com/ZozuliaMykyta/portfolio-v2.git
cd portfolio-v2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
This will run the app in development mode.
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) (or the port specified in the console) to view it in your browser.
